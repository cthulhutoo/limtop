# v0.3.1 "Foundations" Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Ship the v0.3.x foundations from ROADMAP.md — `--json`/`--once`, `--dump --watch`, `~/.config/limtop.toml`, and release binaries with an instant brew install — as limtop v0.3.1 on crates.io + GitHub + homebrew-limtop.

**Architecture:** All work hangs off two existing seams: `Registry::scan(&home) -> Registry{events, statuses}` and `Dashboard::build(events, span, now)`. JSON output serializes those plus `RateWindow`. Config is a small `Config` struct parsed from TOML, threaded into the rate-window plan and Ollama URL (replacing env vars). Release automation extends the existing `ci.yml` into a `release.yml` triggered on tags.

**Tech Stack:** Rust (existing deps + `serde_json`, `toml`), GitHub Actions (macos-13/macos-14/ubuntu runners, `softprops/action-gh-release`).

**Repo:** `~/projects/limtop` · branch off `main` as `v0.3.1`

```rust
use std::path::PathBuf;

#[derive(Debug, Default, serde::Deserialize)]
pub struct Config {
    pub plan: Option<String>,                    // "max5" | "max20" | "max50" | "pro"
    pub ollama_url: Option<String>,
    pub extra_claude_dirs: Option<Vec<String>>,  // ["~/.claude-work"]
    pub pricing: Option<std::collections::HashMap<String, PricingOverride>>,
}

#[derive(Debug, serde::Deserialize)]
pub struct PricingOverride {
    pub input: Option<f64>,        // $/Mtok
    pub output: Option<f64>,
    pub cache_read: Option<f64>,
}

impl Config {
    pub fn load() -> Config {
        let p = dirs::config_dir()
            .unwrap_or_else(|| PathBuf::from("."))
            .join("limtop.toml");
        match std::fs::read_to_string(&p) {
            Ok(s) => toml::from_str(&s).unwrap_or_else(|e| {
                eprintln!("limtop: bad {p:?}: {e}; ignoring"); Config::default()
            }),
            Err(_) => Config::default(),
        }
    }
    /// env var beats file beats default — env stays working for one-offs
    pub fn plan_or_env(&self) -> Option<String> {
        std::env::var("LIMTOP_CLAUDE_LIMIT").ok().or_else(|| self.plan.clone())
    }
}

mod tests {

ollama_url = "http://100.117.188.31:11435"

input = 3.0
output = 15.0
"#;

}
```

## Task 5: Release workflow — binaries on tag push

**Objective:** Tag push builds + attaches prebuilt binaries for linux x86_64, macOS aarch64, macOS x86_64.

**Files:** Create: `.github/workflows/release.yml`

```yaml
name: Release
on:
  push:
    tags: ["v*"]

permissions:
  contents: write

jobs:
  build:
    strategy:
      matrix:
        include:
          - { os: ubuntu-latest,  target: x86_64-unknown-linux-gnu, archive: tar.gz }
          - { os: macos-14,       target: aarch64-apple-darwin,     archive: tar.gz }
          - { os: macos-13,       target: x86_64-apple-darwin,      archive: tar.gz }
    runs-on: ${{ matrix.os }}
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
        with: { targets: "${{ matrix.target }}" }
      - uses: Swatinem/rust-cache@v2
      - run: cargo build --release --target ${{ matrix.target }}
      - name: package
        run: |
          cd target/${{ matrix.target }}/release
          tar czf ../../../limtop-${{ github.ref_name }}-${{ matrix.target }}.tar.gz limtop
      - uses: softprops/action-gh-release@v2
        with:
          files: limtop-${{ github.ref_name }}-${{ matrix.target }}.tar.gz
```

**Verify:** commit, then `git tag v0.3.1-rc1 && git push origin v0.3.1-rc1`, `gh run watch`, confirm 3 assets on the rc release. Delete rc tag + release after.

Commit: `ci: release workflow — linux + macOS binaries on tag push`

**Objective:** crates.io publish, GitHub release, tap update to prebuilt binary.

